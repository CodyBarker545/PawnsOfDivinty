# Unresolved rules register — Stage 6.4

Reviewed 10 November 2026 against Specification v0.2 and actual production code. No option
below is approved by this document. Priorities are development recommendations:
P0 blocks an authoritative playable combat loop; P1 blocks a major ability/common interaction;
P2 limits important balance evidence; P3 is an edge/deferred feature. A reduced sandbox may
explicitly omit a feature, but omission is not implementation of its rule.

Columns combine the requested uncertainty, current behavior, blocked situation, consequence,
design options, decision owner and suggested post-approval stage. Engineering-only gaps are
listed separately at the end so confirmed rules are not misrepresented as undecided.
