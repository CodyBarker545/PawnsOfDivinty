# Combat readiness inventory — Stage 6.4

Review dates: 10–11 November 2026. Entry baseline: 2,781 passing tests, no failures/skips,
no build warnings/errors. Final diagnostic verification is in `Stage6_4_ReadinessSummary.md`.
This inventory describes inspected code and evidence, not new rules or approvals.

Sources: `Docs/Pawns_of_Divinity_Specification_v0.2.md` (6 November 2026), current
`Scripts/Core/`, `Scripts/Gameplay/`, scenario code, and both RepresentativeSuite exports.
Specification section numbers below refer to that exact document. Rule labels are C=confirmed,
P=provisional, U=unresolved. Readiness uses only **Implemented**, **PartiallyImplemented**,
**RuleUnresolved**, **MissingIntegration**, **NotImplemented**. A rule may be C while its
integration is missing; implemented P behavior remains P. Blocker priorities are recommendations.

## Specification ambiguities and guardrails

1. §12.5's trailing “expiration when caster dies (now CONFIRMED persists)” is not scoped to
   an individual effect. §10 clearly preserves already-created terrain and benefits placed
   on other living units. `SanctuaryOfTheForgotten.Evaluate` still returns `SourceDeathUnresolved`
   for a qualifying continuously calculated dead-source aura; Sentinel tracker retires a dead
   owner. Record the scope ambiguity (R25), not a new ruling. Wall/ice/smoke persistence is settled.
2. §12.6 says “150% bonus” in its equipment sentence, while §4.1 and the approved Stage 5.9A
   instruction specify **150% total**. Use total, not +150%; only rounding/order/classification remain open.
3. §15's suggested `UnitState` is architectural advice, not permission to duplicate `Character`.
   Existing Character remains the runtime authority. Older generic §17 questions do not undo
   finalized Gentle Blessing, Roar, or Knockback core decisions in §§12.2/12.4.
4. Shadow Strike's pre-approach invisibility timing is an explicit approved Stage 5.4D ruling
   recorded in source comments/tests and the conversation, beyond the terse §12.1 wording.
   Preserve it; do not disable adjacency reveal or grant an unspecified approach move.

The core supports measured deterministic arithmetic and explicit supported combat actions.
It does not yet support unrestricted complete encounters or competitive balance conclusions.
Read `BalanceRiskReview.md` for experiment interpretation, `UnresolvedRules.md` for decisions,
